// PASO 1 — Estructura MongoDB en mongosh (1:00-2:30)
//////////////////////////////////////////////
// Conectar:
//   mongosh "mongodb://localhost:27017/automoviles"
//
// a) Un documento de ejemplo (qué campos tiene):
//   db.vehiculos.findOne({ nombre: "Barco" }, { _id: 0 })
//   -> ESPERADO: {nombre, categoria:"Acuático", peso_toneladas:500, descripcion}
//   QUÉ DECIR: "Cuatro campos; nombre es clave con índice único, categoría
//   es el campo identificador del caché."
//
// b) Conteo por categoría (cuántos hay de cada una):
//   db.vehiculos.aggregate([
//     { $group: { _id: "$categoria", total: { $sum: 1 } } },
//     { $sort: { _id: 1 } }
//   ]).toArray()
//   -> ESPERADO: Aéreo 2, Acuático 2, Espacial 1, Terrestre (motorizado) 3,
//      Terrestre (no motorizado) 2. Total 10.
//
// c) Matriz de caché (lógica espejo de la API, evidencia de las bandas):
//   db.vehiculos.aggregate([
//     { $project: { _id: 0, nombre: 1,
//       ttl_esperado_s: { $switch: { branches: [
//         { case: { $gt: [{ $strLenCP: "$categoria" }, 20] }, then: 0 },
//         { case: { $lte: [{ $strLenCP: "$categoria" }, 5] }, then: 15 },
//         { case: { $lte: [{ $strLenCP: "$categoria" }, 10] }, then: 20 } ],
//         default: 40 } } } } },
//     { $sort: { ttl_esperado_s: 1, nombre: 1 } }
//   ]).toArray()
//   -> ESPERADO: 15s Avión/Helicóptero; 20s Barco/Lancha/Cohete;
//      0 (NO_CACHE) los 5 Terrestre.
//   QUÉ DECIR: "El seed cubre C1, C2 y C4; C3 la demuestra el Integrante 3."

//////////////////////////////////////////////
// PASO 2 — C2: GET Barco MISS + HIT (6:50-8:00)
//////////////////////////////////////////////
// Punto de partida limpio:
//   wsl redis-cli DEL "vehiculo:Barco"
// Postman "11 GET Barco 1er -> mongodb":
//   GET http://localhost:5000/vehiculos/Barco
//   -> ESPERADO 200 (fuente mongodb, ttl_segundos 20)
// QUÉ DECIR: "Acuático mide 8 caracteres, banda de 20 segundos. MISS desde Mongo."
//
// WSL:
//   wsl redis-cli TTL "vehiculo:Barco"
//     -> ESPERADO: entre 18 y 20
// Postman "12 GET Barco 2do -> redis":
//   GET http://localhost:5000/vehiculos/Barco
//   -> ESPERADO 200 (fuente redis)
// QUÉ DECIR: "HIT desde Redis; el TTL corre."
